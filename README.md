# 제타 텍스트 보관함+

**Plus v0.1.0 설계 단계 · 아직 설치 가능한 유저스크립트가 배포되지 않았습니다.**

기존 [제타 텍스트 보관함](https://github.com/casualJH/zeta-text-library)에 **제타 채팅 입력창 `/` 단축어 검색·삽입 기능**을 추가하는 독립 개발 프로젝트입니다.

## 설계 문서

**[v0.1.0 기획·기술 설계안](docs/DESIGN-v0.1.0.md)**

기획안에는 슬래시 단축어 UI, 채팅 iframe 통신·연결 확인, 접근 안내 팝업, Dock에서의 **텍스트 보관함+** 명칭 구분, 데이터 백업·이전 및 테스트 기준을 담았습니다.

## 정식판과의 관계

- 기존 `casualJH/zeta-text-library`의 **v1.0.2 정식판은 수정하지 않습니다.**
- Plus는 별도 스크립트 이름·네임스페이스·저장 키를 사용하도록 설계합니다.
- 기존 텍스트는 정식판에서 JSON 백업을 만든 뒤 Plus에 **복사하여 이전**하는 것을 기본으로 합니다. 두 버전은 자동 동기화하지 않습니다.
- Plus는 **v0.1.0 개발 버전**부터 시작하며, 구현·실기기 테스트 후 별도로 배포합니다.
